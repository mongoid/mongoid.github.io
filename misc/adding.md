## Moving a Project to the Mongoid Org

We encourage you to move projects into the Mongoid org to reduce bus factor. This enables continuity when you decide that you no longer want to be involved in your project.

1. [Open an issue](https://github.com/mongoid/mongoid.github.io/issues) with some information about the project.
2. Coordinate the transfer and appropriate repository permissions with the current organization maintainers.
3. Transfer the project into the mongoid organization. You will continue maintaining it; work with the organization maintainers to invite additional contributors.
4. Arrange RubyGems co-ownership with the current maintainers so releases do not depend on a single account.
5. Update repository links, gem metadata, badges, and documentation to use the new canonical location.
6. Add or maintain GitHub Actions checks for the project's supported Ruby, Mongoid, and MongoDB versions, along with relevant tests and coverage.
7. Propose a homepage entry with a short description once the project has active maintenance. Each project should document its own compatibility and release process.

Thank you, we love you!
